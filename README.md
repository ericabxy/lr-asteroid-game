# LR Asteroid Game

An asteroids clone written in C for LibRetro.

![Screenshot of Asteroid Game in progress.](screenshots/Asteroid Game-261001-102655.png?raw=true)

## Getting Started

    make
    retroarch -L asteroid_game_libretro.so

## Cleaning Up

    make clean

## Bugs

- New asteroids spawn in the wrong locations when parent is destroyed.
